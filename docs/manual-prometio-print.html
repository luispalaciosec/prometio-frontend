Sección 1

Introducción y acceso

prometIO centraliza contactos, oportunidades, cotizaciones, actividades y configuración de la agencia. Frontend en Vercel, API en Railway, datos en Supabase.

1.1 Ingresar al sistema

  1. Abrí https://prometio.vercel.app en el navegador.
  2. Iniciá sesión con Google o email/contraseña (cuenta previamente invitada).
  3. La app carga tu perfil, tema claro/oscuro y permisos según tu rol.
Los administradores invitan usuarios en Configuración → Usuarios. El invitado completa el registro en /auth/invitacion.

Sección 3

CRM: contactos y empresas

3.1 Contactos

Listado con búsqueda por nombre, email o teléfono; filtro por etapa de ciclo de vida; vista lista o cuadrícula.

  • Detalle en /contactos/:id con timeline y oportunidades vinculadas.
  • Desactivar contacto (no borrado físico).
  • Leads del formulario web crean contacto automáticamente.

3.2 Bandeja multicanal

Conversaciones de WhatsApp, Instagram, etc. Convertir a contacto es siempre manual — nunca automático.

Sección 4

Negocios: pipeline

4.1 Pipeline (Kanban)

Nueve etapas fijas. Arrastrá tarjetas para cambiar etapa. El valor se muestra como estimado (valor_referencial) o cotizado cuando existe valor_cotizado.

La "vista por servicio" es un filtro sobre el mismo pipeline, no una pantalla distinta.

Sección 4

Cotizaciones

4.2 Lista y constructor

Lista global en /cotizaciones. Al hacer clic se abre el constructor en la oportunidad correspondiente.

PDF para el cliente: nunca muestra desglose de costo/margen — solo el total. La vista interna con desglose depende de permisos del usuario logueado.
  • Calculadora en vivo: costo → margen → comisión → impuestos.
  • Descuento > 10 % o comisión baja → envío a aprobación.
  • PDF con QR de verificación pública.

Sección 8

Formulario web

Ruta admin: /configuracion/formulario-web — cinco pestañas: Embed, Campos, Apariencia, Webhooks, Medición.

8.1 Embed y campos

  • Snippet HTML para copiar a la landing del cliente.
  • Nombre completo fijo y requerido; resto configurable en tab Campos.
  • UTM capturados: utm_source, utm_medium, utm_campaign, utm_content, utm_term, fbclid, gclid.
prometIO · Manual de usuario§ 8
Sección 8

Medición (Meta + GA4)

Meta Pixel: el widget dispara fbq('track', 'Lead', {}, { eventID }) solo si la API responde lead_creado: true.
GA4: el widget no dispara generate_lead en el navegador — solo lee client_id y lo envía como ga_client_id. La conversión la registra únicamente el backend.

8.2 Tab Medición (admin)

  • Estado operativo: hCaptcha, Meta CAPI, GA4 Measurement Protocol.
  • Configuración de credenciales (tokens nunca se muestran en GET — solo flags _configurado).
  • Log paginado de eventos enviados (GET /config/ads-tracking/eventos).

8.3 Webhooks salientes

  • Evento contacto.creado_formulario con firma HMAC.
  • El secreto solo se muestra una vez al crear el webhook (modal POST).
